# Dharma Slider

[![Release](https://img.shields.io/github/v/release/shivayanamahom/mod-dharma-slider?color=blue)](https://github.com/shivayanamahom/mod-dharma-slider/releases)
[![Joomla](https://img.shields.io/badge/Joomla-5.x%20%7C%206.x-orange.svg)](https://www.joomla.org/)
[![License: GPL-2.0+](https://img.shields.io/badge/License-GPL--2.0%2B-blue.svg)](LICENSE)

Адаптивный модуль слайдера для Joomla. Подходит для главной страницы и других позиций шаблона. Слайды и их содержание редактируются в настройках модуля.

## Возможности

- Несколько слайдов с изменением порядка в административной панели.
- Заголовок, подзаголовок, изображение и цвет фона для каждого слайда.
- Цвета текста и настраиваемая подложка для читаемости поверх изображения.
- До двух ссылок-кнопок на слайде с настройкой текста, адреса, CSS-классов, иконки и открытия в новой вкладке.
- Автоматическое переключение с настройкой интервала, стрелки и индикаторы слайдов.
- Переопределение макета средствами Joomla и выбор альтернативного макета.

## Установка

Требуются Joomla 5 или 6 и PHP 8.1 или новее. Текущий выпуск проверен на Joomla 6.

### По ссылке

В административной панели Joomla откройте **Система → Установка → Расширения → Установить по URL-адресу** и укажите:

```text
https://github.com/shivayanamahom/mod-dharma-slider/releases/latest/download/mod_dharma_slider.zip
```

### Из архива

Скачайте ZIP с последней версией на странице [Releases](https://github.com/shivayanamahom/mod-dharma-slider/releases/latest) и установите его через **Система → Установка → Расширения → Загрузить файл пакета**.

После установки создайте модуль **Dharma Slider** в разделе **Содержимое → Модули сайта**, выберите позицию и страницы отображения, добавьте слайды и опубликуйте модуль.

## Настройка

В каждом слайде укажите необходимые текст, изображение и кнопки. Для кнопки заполните и текст, и ссылку. Поля CSS-класса позволяют использовать оформление вашего шаблона. Ссылки поддерживают относительные адреса, HTTP, HTTPS, телефон и электронную почту.

В настройках модуля можно отключить автопрокрутку или указать интервал в секундах. Если все строки подзаголовка начинаются с символа «•» и пробела, модуль показывает их списком с отметками.

Встроенные стили находятся в `media/mod_dharma_slider/slider.css`. Для оформления конкретного сайта используйте стили своего шаблона.

## Оверрайды

В Joomla откройте **Система → Шаблоны сайта**, выберите шаблон и создайте переопределение модуля **mod_dharma_slider**. Joomla разместит копию макета по пути:

```text
templates/ИМЯ_ШАБЛОНА/html/mod_dharma_slider/default.php
```

Можно создать альтернативный макет в этой же папке и выбрать его в дополнительных настройках модуля. Оверрайд принадлежит шаблону и сохраняется при обновлении расширения. После обновлений сверяйте его с новым `tmpl/default.php`, чтобы использовать изменения разметки.

## Обновление

Расширение подключает свой источник обновлений. Проверяйте новые версии в **Система → Обновление → Расширения**. Настройки и слайды существующего модуля сохраняются при обновлении.

## Сборка из исходников

```bash
./build.sh
```

Скрипт создаёт установочный ZIP в `dist/` и выводит его SHA-256. Публикация новой версии требует обновления версии в манифесте и `updates.xml` и размещения архивов в GitHub Releases.
