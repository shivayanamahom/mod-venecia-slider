# Venecia Slider

Модуль слайдера для сайта санатория «Уральская Венеция» на Joomla. Слайды, ссылки и параметры автопрокрутки редактируются в настройках модуля.

Установка и обновление выполняются через менеджер расширений Joomla. Готовый архив находится в разделе Releases. Настройки существующего экземпляра модуля сохраняются при обновлении.

Для выпуска следующей версии измените номер версии в манифесте и updates.xml, соберите ZIP с манифестом в корне и опубликуйте архив в соответствующем GitHub Release.
